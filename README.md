# Oblivio

## 📖 프로젝트 소개
**Oblivio**는 언리얼 엔진 5(Unreal Engine 5)를 기반으로 개발된 3D 탑뷰 생존 호러 게임입니다. 플레이어는 폐쇄된 병원이라는 극한의 환경 속에서 제한된 자원(허기, 플래시라이트 배터리)을 관리하며, 기괴한 변이 생명체들을 피해 생존해야 합니다. 단순한 탈출을 넘어, 병원 곳곳에 남겨진 단서(Memento)를 수집하여 감춰진 진실을 파헤치는 것이 이 게임의 핵심 목표입니다.

---

## 📜 스토리
알 수 없는 이유로 봉쇄된 병원. 플레이어는 과거의 기억을 잃은 채 9층 휴게실(Doctor's Lounge)에서 눈을 뜹니다. 
전력이 끊기고 곳곳에 핏자국과 알 수 없는 파편들이 널브러져 있는 가운데, 기괴한 괴물(Luxeater, Crawling Flesh Mass 등)들이 복도를 배회하고 있습니다. 
아래층으로 내려갈수록 병원을 덮친 끔찍한 재난과 마주하게 되며, 수집한 일지와 쪽지들을 통해 자신에게 얽힌 충격적인 진실에 다가가게 됩니다.

## 📂 파일 구조
프로젝트의 핵심 C++ 소스 코드 및 블루프린트 구조는 다음과 같습니다.

~~~text
Oblivio/
├── Content/
│   ├── AssetResource/         # 3D 모델링, 텍스처, 머티리얼 에셋
│   ├── Blueprints/            # C++ 클래스를 상속받은 블루프린트 (캐릭터, 아이템, UI)
│   ├── LevelSequence/         # 층별 오프닝 및 컷신 시네마틱
│   ├── Localization/          # 다국어(한/영) 번역 데이터 (.locres, .po)
│   ├── Map/                   # 레벨 데이터 (MainMenuMap, L_Floor9 ~ L_Floorb1 등)
│   └── UI/                    # UI 위젯 블루프린트 및 폰트 에셋
└── Source/
    └── Oblivio/
        ├── Public/            # C++ 헤더 파일 (.h)
        └── Private/           # C++ 소스 파일 (.cpp)
            ├── AIEnemy/              # 적 AI 상호작용 및 시야/소리 감지 로직
            ├── Crafting/             # 빛 데미지 및 보스 패턴 로직
            ├── Crafting/             # 크래프팅 및 장애물 설치 로직
            ├── Items/                # 아이템 픽업, 사용 및 인벤토리 로직
            ├── Notify/               # 애니메이션 타이밍에 맞춰 이벤트 발생 로직
            ├── OblivioComponents/    # 전투, 소리 전파, 빛 공격 로직
            ├── UI/                   # C++ 기반 UI 위젯 제어 로직
            ├── Weapon/               # 투척물(Projectile) 및 유인 메커니즘
            └── OblivioCharacter.cpp  # 플레이어 이동, 조작 및 핵심 상태 관리
~~~

## 🎮 조작법
| 조작 키 | 액션 | 설명 |
| :--- | :--- | :--- |
| **W, A, S, D** | 이동 | 캐릭터 기본 이동 |
| **마우스 이동** | 시점 전환 | 카메라 시점 이동 |
| **Space** | 점프 | 장애물을 넘거나 뛰어오름 |
| **Ctrl** | 앉기 | 자세를 낮춰 발소리를 줄이고 좁은 곳 통과 |
| **L-Shift** | 달리기 | 스태미나를 소모하여 빠르게 이동 |
| **E** | 상호작용 | 아이템 줍기(Pick Up), 문 열기, 단서(Memento) 읽기 등 |
| **F** (토글) | 플래시라이트 | 손전등 켜기/끄기 (배터리 지속 소모) |
| **Q** | 섬광탄 | 배터리를 소모해서 섬광탄 투척 |
| **Tab** | 인벤토리 | 인벤토리 창 열기/닫기 |
| **1, 2, Z** | 퀵 슬롯 | 등록된 소모성 아이템 빠르게 사용 |
| **C** (토글) | 크래프팅 모드 | 크래프팅 메뉴 진입 및 장애물 제작 |
| **C 누른 상태 + 1~5** | 장애물 선택 | 크래프팅 모드 중 설치할 장애물 종류 선택 |
| **Z** (크래프팅 중) | 회전 | 설치할 장애물 및 오브젝트의 방향 회전 |
| **마우스 좌클릭** (크래프팅 중) | 설치 | 장애물 설치 |

## 🌊 게임 흐름
1. **탐색 및 생존:** 각 층(9층 ~ 지하 1층)을 탐색하며 나아갈 길을 찾습니다. 시간이 지남에 따라 허기 수치가 떨어지므로, 지속적으로 `Food`를 찾아 섭취해야 합니다.
2. **자원 관리:** 어두운 구역을 통과하기 위해 플래시라이트가 필수적이나, `Battery`는 한정되어 있습니다. 
3. **크래프팅 및 은신:** 병원 내에는 시각과 청각에 예민한 변이체들이 존재합니다. `C` 키를 활용해 장애물을 제작하여 길을 막거나, 투척물(유리병)을 던져 소음을 내어 적의 시선을 돌려야 합니다.
4. **단서 수집:** 각 층에 숨겨진 열쇠(Key)를 찾아 잠긴 문을 열고, 흩어진 기억의 조각(Memento)을 모아 도감(Bestiary)과 스토리를 완성합니다.
5. **다음 층으로 이동:** 층마다 발생하는 특수 기믹을 돌파하고 최종 목적지에 도달해야 합니다.
